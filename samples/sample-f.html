Section §2 · Definition · 2 exercises

A prompt file is not a harness

A harness is the engineering infrastructure outside the model weights. It has five subsystems. The prompt is one artefact inside the first of them, and treating it as the whole thing is the most common reason agent sessions fail.

2.1Subsystem inventory

Every harness decomposes into the same five parts. Each has a distinct responsibility and a distinct way of failing; when a session goes wrong, the first job is to name which one broke.1

SubsystemResponsibilityArtefacts
InstructionsRules, conventions, definition of doneAGENTS.md, docs/
ToolsWhat the agent can actually doshell, test runner, linters
EnvironmentA runnable, isolated place to workinit.sh, lockfiles
StateWhat is done, why, and what is nextfeature_list.json
FeedbackEvidence of what actually happenedtests, traces, logs
Note 2.1.a — measurement To establish which subsystem is load-bearing today, remove one at a time and re-run an identical task. The largest regression identifies the investment; a removal with no effect identifies something you can delete.

2.2Minimum-strength rule

A harness is a chain, not a portfolio. Session reliability is bounded by the weakest subsystem, so improving any other layer produces no observable gain until the weakest one is repaired. A strong instruction file cannot rescue an agent that cannot execute the test suite; a complete test suite does nothing if the agent never learns its own state.

Score each subsystem from 0 (absent) to 4 (maintained). The governing figure is the minimum, not the mean.2

Common error 2.2.a Teams average their scores, see a healthy 3.2, and conclude the harness is fine. The single 1 in environment is the only number that predicts their next failed session.

2.3Worked example

A four-person team scores 3 / 2 / 1 / 2 / 3 across the five subsystems: 11 of 20, a mean of 2.2. Two of the three sessions in the following week ended with unverified work, and both failed in the environment layer — a cold clone could not install dependencies. The fix was one script, not a rewrite of the instruction file they had spent three weeks expanding.
